SQL Queries Used In Project

Feature Description
Top Restaurants Find restaurants with highest orders
Total Revenue Calculate overall revenue
Order Status Analysis Track order lifecycle
Top Customers Identify frequent customers
Monthly Revenue Revenue trend analytics

🏆 Top Restaurants

SELECT r.restaurant_name,
COUNT(o.order_id) AS total_orders
FROM restaurants r
LEFT JOIN orders o
ON r.restaurant_id = o.restaurant_id
GROUP BY r.restaurant_id
ORDER BY total_orders DESC;

💰 Total Revenue

SELECT SUM(amount) AS total_revenue
FROM payments;

📦 Order Status Analysis

SELECT order_status,
COUNT(*) AS total_orders
FROM orders
GROUP BY order_status;

👤 Top Customers

SELECT u.name,
COUNT(o.order_id) AS total_orders
FROM users u
JOIN orders o
ON u.user_id = o.user_id
GROUP BY u.user_id
ORDER BY total_orders DESC;

📈 Monthly Revenue Trend

SELECT DATE(payment_date) AS day,
SUM(amount) AS revenue
FROM payments
GROUP BY DATE(payment_date)
ORDER BY day;

⭐ Average Restaurant Ratings

SELECT r.restaurant_name,
AVG(rv.rating) AS average_rating
FROM restaurants r
JOIN reviews rv
ON r.restaurant_id = rv.restaurant_id
GROUP BY r.restaurant_id;
