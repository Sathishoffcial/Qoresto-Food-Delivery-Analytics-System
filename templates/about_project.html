QORESTO

Analytics & Food Ordering Management Platform

📌 Project Overview

Qoresto is a full-stack Food Ordering and Analytics System developed using Flask, MySQL, HTML, CSS, JavaScript and Chart.js. The platform provides restaurant management, customer ordering, analytics reporting and admin controls.

💻 Technology Stack

  • Python Flask
  • MySQL Database
  • HTML5
  • CSS3
  • JavaScript
  • Chart.js
  • OpenPyXL

🗄 Database Tables

  • Users
  • Restaurants
  • Menu
  • Orders
  • Payments
  • Reviews
  • Favorites
  • Cart
  • Notifications

🚀 Project Features

  • User Login & Registration
  • Restaurant Management
  • Menu Management
  • Shopping Cart System
  • Order Placement
  • Payment Tracking
  • Reviews & Ratings
  • Favorites Management
